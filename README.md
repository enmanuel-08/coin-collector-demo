# Coin Collector - Unity Demo

A 3D maze game made with Unity WebGL. Control a cube, collect 5 coins to win. Movement is click-based using NavMesh.

## 🎮 Play online
[Click here to play](https://enmanuel-08.github.io/coin-collector-demo/)

## 🕹️ How to play
- **Move:** Click on any walkable area (the ground inside the maze)
- **Objective:** Collect all 5 golden coins
- **Win:** A message will appear when you collect the 5th coin

## ✅ Features
- NavMesh-based movement (click to move)
- Coin collection with rotation animation
- Win condition UI
- Restart button (Play Again)

## 🛠️ Technologies
- Unity WebGL
- C#
- NavMesh (AI pathfinding)
- GitHub Pages
